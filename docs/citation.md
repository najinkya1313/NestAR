# Citation

If you use NestAR in your research or other work, please cite the accompanying paper:

> **A. J. Naik and W. Handley**, *Nested Sampling for ARIMA Model Selection in Astronomical Time-Series Analysis*.

The paper is available on arXiv:

https://arxiv.org/abs/2512.01929

## Software

NestAR is open-source software for Bayesian ARIMA model selection using Nested Sampling. The source code and documentation are available in the [GitHub repository](https://github.com/najinkya1313/NestAR).
